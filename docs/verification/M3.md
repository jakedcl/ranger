## What works

- Seeded **Project coordinator** template bound to Harbor Design Security + Harbor SketchUp
- Person → Start onboarding / offboarding → frozen preview → approve → execute
- **Change status** opens a checklist run; **Departed** steers to full offboarding (not a silent patch)
- Person overview lists open lifecycle runs with checklist links; Overview joiner/leaver board
- Demo provider creates one account, direct group membership, one named-seat assignment
- Mailbox step is **manual** (mail attribute is not treated as mailbox proof)
- License failure leaves the created account; retry does not create a second account
- Technician without `automation_execute` can preview/approve but cannot execute Graph writes
- Approved runs keep their frozen template version after a later template edit
- Offboarding approval records **Departed** immediately with `offboarding_in_progress`; status_change waits for execute
- Group member removal URL is `DELETE /groups/{id}/members/{id}/$ref` (unit-tested)
- Local web origins: `127.0.0.1:5173` and `localhost:5173`
